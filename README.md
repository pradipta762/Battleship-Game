# 🚢 Battleship Game

A simple browser-based Battleship game where players try to locate hidden ships on a grid within a limited number of attempts.

## 🌐 Live Demo

🔗 [Play the game here](https://pradipta762.github.io/Battleship-Game/)

## 🛠 Tech Stack

- HTML  
- CSS  
- JavaScript

## 🎮 How to Play

- Click on the cells to reveal what’s hidden behind them.
- There are **5 ships** hidden randomly in the grid.
- You **win** if you find all ships in **less than 8 clicks**.
- If not, you **lose** the game.
